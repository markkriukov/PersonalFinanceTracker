# PersonalFinanceTracker - Трекер особистих фінансів

## Мета:
Розробити застосунок для відстеження доходів і витрат, зберігаючи фінансові дані в базі даних SQLite

## Особливості:
* Вести доходи з описом виду доходів, суми та дати отримання на окремій активності.
* Вести витрати із зазначенням категорії витрат (продукти, одяг, транспорт тощо), опису витрат, суми та дати витрати на окремій активності.
* Виводити список доходів і витрат з можливістю фільтрації за датами, каткгоріями, видами з підрахунком суми для відфільтрованих записів.
